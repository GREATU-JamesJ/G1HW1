로그 형식
  [가상 시각] 노드 | 이벤트 | 상태 | 내용

상태
  INFO    일반 진행 정보
  SUCCESS 연결, 처리, 이전, 종료 성공
  FAIL    처리 실패, Queue 초과, 연결 실패
  WARN    Queue 70% 초과, 알 수 없는 프로토콜 메시지

이벤트
  INIT       Master 시작, KV 작업 5,000개 생성
  CONNECT    Worker 연결, 연결 해제
  RECV       Master 작업 수신
  DISTRIB    Master 작업 배정, 전체 처리 완료
  RESULT     Worker 성공·실패 결과 수신
  PROC       Worker 작업 처리 결과
  QUEUE      Queue 용량 경고, 초과 거부
  LB         Worker 간 P2P 작업 이전·수신·ACK 확인, 이전 KV 번호 기록
  PROTO      알 수 없는 네트워크 메시지
  STAT       Master·Worker 최종 통계
  TERMINATE  정상 종료 신호, 종료 완료

Worker 실행 결과 보조 파일
  runs/<시작시각>-<UUID>/ 아래에 기존 노드별 로그 이름을 유지한다.
  summary.txt: 모든 Worker 종료 후 통합 통계와 Master 로그 검증 결과
  run.json: 실행 ID, 서버 주소, 시작/종료 시각, 실제/가상 시간, 실행 상태
  상태: RUNNING / COMPLETED / PARTIAL / FAILED / ABORTED
  상세 화면 ON/OFF는 파일 이벤트 기록에 영향을 주지 않는다.
  화면의 '실행 오류'는 통신/프로그램 오류이며, PROC FAIL 시뮬레이션 실패와 구분한다.
